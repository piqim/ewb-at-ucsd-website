02 — Homepage wireframe

Homepage layout — desktop view

Full-page wireframe top to bottom. Placeholder blocks represent real photos and dynamic content. The layout adapts to tablet and mobile via Tailwind responsive classes.

Placeholder content: All photos, logos, and member images shown as colored blocks in the wireframe are placeholders. Replace with real assets before launch. For local dev, use /public/placeholder.jpg or any free Unsplash image.
① Hero
Full-width video or image. Two CTA buttons: "Learn More" (white outline) and "Join the Club" (gold fill). Scroll hint arrow at bottom.
② Mission strip
Subtle blue-tinted band. Shows EWB-UCSD logo, one-line tagline, and the inclusivity statement. Static — no admin editing needed.
③ Stats counters
Four animated count-up cards. Values hardcoded or editable via admin. Uses countUp.js (free) for animation on scroll.
④ Project cards
Three cards, one per project. Photo, colored badge, description, and CTA. Data pulled from MongoDB projects collection.
⑤ Get involved CTA
Navy background section with three icon cards. Targets prospective members. Links to the Get Involved page or the join form.
⑥ Stay connected
Advisory note + free Discord widget (iframe embed) + Instagram profile card (static link). No API costs. Zero maintenance.
⑦ Footer
Navy background. Logo, copyright, privacy link, contact link, Instagram and Discord links. Static — update annually.
Navbar
Sticky on scroll. Hamburger menu on mobile. "Join Us" gold pill button always visible. Links to all six primary nav pages.
